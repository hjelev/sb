Keyboard first, all the way down

The most-used keys. Press h in sb for the full help overlay.

Navigation

  • Enter→Open entry or preview file
  • ←BkspParent directory, or leave a mount
  • SpaceMark or unmark entry
  • *Toggle all marks
  • `Switch view mode
  • ~Go to home
  • .Show or hide hidden files
  • /Filter the folder
  • 0–9Jump to bookmark

File operations

  • cCopy to clipboard
  • vPaste
  • mMove (cut and paste)
  • dDelete, with confirmation
  • rF2Rename, or bulk rename
  • nNew file or folder
  • xToggle executable bit
  • pEncrypt or decrypt with age

Power tools

  • GGit commit workflow
  • Ctrl+GAI commit message, in the commit prompt
  • fSearch overlay
  • gContent search with rg
  • ZCreate or extract an archive
  • SSSH and rclone remotes
  • IIntegrations panel
  • ;Run a shell command
  • Ctrl+ZDrop to a shell here
