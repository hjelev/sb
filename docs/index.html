Shell Buddy

A keyboard-driven terminal file manager, written in Rust. One small binary for fast local navigation, with previews, archives, search, remote mounts and Git whenever you need them.

$cargo install shell-buddy
Install View on GitHub

Built for people who live in the terminal

Every workflow is a keystroke away, so you never have to leave the file manager.

  • G

    Git, without leaving

    Diff preview, status review, commit, push and an optional tag, all from inside sb.

  • Ctrl+G

    AI commit messages

    Draft a commit message from the diff with one keypress (Groq or GitHub Models), then edit it before committing.

  • Tab

    Inline path filters

    Type ^prefix, suffix$ or ~contains in the path bar to filter the listing as you type.

  • I

    One-key tool installs

    See which optional tools are missing and install them through Homebrew from the integrations panel.

  • p

    Age encryption

    Encrypt a file to .age, or decrypt one, in place.

  • Ctrl+N

    Per-file notes

    Attach a note to any file. Notes live in a hidden .sb file in each directory.

  • iE

    tmux-aware splits

    i opens a shell and preview pane, E a shell and editor pane. Uses zellij when tmux isn't installed.

  • Ctrl+E

    Edit the clipboard

    Open whatever is on the system clipboard in $EDITOR.

  • sb -l

    List and tree output

    sb -l, sb -t and sb -l2 print aligned columns; sb <file> opens a file in the best viewer.

  • T

    Themes

    Nord, Dracula, Gruvbox, Rosé Pine, Everforest and more, with Nerd Font icons and file colors switched live.
